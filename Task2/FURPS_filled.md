# FURPS+ таблица (депозиты + кредиты)

## F — Функциональные требования

| Код | Требование | Комментарий |
|-----|------------|-------------|
| F1 | Подача заявки на депозит на сайте новым клиентом | Передача чувствительных данных по HTTPS/TLS. |
| F2 | Подача заявки на депозит в интернет-банке | Указание продукта, суммы, счёта списания. |
| F3 | Подача заявки на кредит на сайте новым клиентом | Возможность предскоринга по данным БКИ. |
| F4 | Подача заявки на кредит в интернет-банке | Поддержка предодобренных предложений. |
| F5 | Подтверждение операций СМС-кодом | Реализуется силами банка, не подрядчика. |
| F6 | Просмотр клиентом списка депозитов и кредитов | Актуальные ставки, персональные ставки. |
| F7 | Предодобренные кредитные предложения | Используются данные скоринга. |
| F8 | Уведомления по СМС о статусах заявки | После подтверждения ставки и открытия. |
| F9 | Обработка заявки бэк-офисом (MVP) | Подтверждение ставки и договора в АБС. |
| F10 | Особые условия через кол-центр | Передача заявки в систему кол-центра. |
| F11 | Обработка кредитов в Кредитном конвейере | Интеграция сайта/ИБ с конвейером. |
| F12 | Получение скоринга из БКИ | Для новых клиентов — только общие данные. |
| F13 | Продолжение работы по ранее поданной заявке | Сотрудник видит заявку из сайта/ИБ. |
| F14 | Централизованное хранение ставок депозитов | В АБС или отдельном сервисе ставок. |
| F15 | Интеграция сайта и ИБ через единый backend | API Gateway/сервис заявок. |
| F16 | Создание договора в АБС | Мануально (MVP), автоматизация позже. |

## +R — Restrictions (Ограничения)

| Код | Требование | Комментарий |
|-----|-------------|-------------|
| +R1 | ИБ несовместим с Kafka | Нужен интеграционный слой. |
| +R2 | АБС масштабируется вертикально | Поэтому нельзя нагружать онлайн. |
| +R3 | Единый backend для сайта и ИБ | Избегаем дублирования логики. |
| +R4 | Нельзя менять ядро ИБ | СМС реализуем сами. |
| +R5 | Batch-обмен кредитов раз в сутки | Ограничение АБС. |
| +R6 | Скоринг перегружен | Запросы только при заявке. |
| +R7 | Идентификация только офлайн | Интернет-банк может только принимать заявки. |
| +R8 | Чувствительные данные нельзя хранить на веб-сервере | Только на backend в зашифрованном виде. |
| +R9 | ИБ сейчас не отказоустойчив | Нужна новая архитектура. |
| +R10 | Все интеграции должны логироваться | Требования ЦБ РФ. |
